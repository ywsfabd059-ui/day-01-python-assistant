My Personal Assistant 🐍

My first Python project, built as part of my 60-day coding challenge.

📌 About the Project

This is a simple command-line personal assistant built with Python. It welcomes the user, displays the current date, calculates the number of days remaining until December 10, 2026, and asks about their career goal.

✨ Features

- Greets the user by name.
- Calculates the days remaining until the project deadline.
- Asks the user about their career goal.
- Displays a personalized welcome message.

🛠️ Technologies Used

- Python
- "datetime" module
- User input and output

▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

python .main.py

- Working with dates using Python's "datetime" module.
