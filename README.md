My Personal Assistant 🐍

My first Python project, built as part of my 60-Day Coding Challenge.

📌 About the Project

My Personal Assistant is a beginner-friendly command-line application built with Python. It collects user information, tracks a project deadline, provides career-goal suggestions, and helps users take their first steps toward their goals.

This project is part of my journey to develop practical programming skills and work toward becoming an AI Engineer.

✨ Features

- Greets users by name.
- Displays the current date.
- Calculates the days remaining until December 10, 2026.
- Asks users about their career goals.
- Provides goal-specific suggestions for AI, web development, and freelancing.
- Recommends a practical first task based on the user's goal.
- Includes a simple progress check using user input.

🛠️ Technologies Used

- Python
- "datetime" module
- Variables and user input
- Conditional statements ("if", "elif", "else")
- String methods such as "lower()"
- Basic date calculations

▶️ How to Run

1. Install Python.

2. Clone or download this repository.

3. Open a terminal in the project folder.

4. Run the application:
   
   python .main.py
